# 📊 E-Commerce Sales & Profit Dashboard

An interactive Power BI dashboard designed to analyze
e-commerce sales, profitability, customers, products,
payment modes, and regional performance.

## 🎯 Project Overview

This project transforms raw e-commerce transaction data
into an interactive business intelligence dashboard.

The dashboard helps answer questions such as:

- Which states generate the highest sales?
- Which months are most profitable?
- Which customers contribute the most sales?
- Which categories have the highest quantity sold?
- Which sub-categories generate the most profit?
- Which payment modes are most commonly used?

## 📊 Dashboard Analysis

### 🌎 Sales by State
Analyzes sales performance across different states
and identifies high-performing regions.

### 💳 Payment Mode Analysis
Shows the distribution of units sold across different
payment methods.

### 📅 Monthly Profit Trend
Analyzes monthly profitability and identifies
strong and weak periods.

### 👥 Customer Analysis
Highlights customers contributing significantly
to overall sales.

### 🛍️ Category Analysis
Shows product quantity distribution across categories.

### 🏆 Sub-Category Profitability
Compares profit generated by different product
sub-categories.

## 💡 Key Insight

The dashboard demonstrates that high sales volume
does not always translate into high profitability.

Analyzing both sales and profit provides a more
complete picture of business performance.
